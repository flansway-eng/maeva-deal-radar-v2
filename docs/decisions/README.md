# Décisions d'architecture (ADR)

Ce dossier contient les Architecture Decision Records du projet.

Chaque ADR est un fichier numéroté (`0001-titre.md`, `0002-titre.md`, ...) au
format standard :

- **Context** : pourquoi cette décision se pose maintenant
- **Decision** : ce qui a été décidé
- **Consequences** : ce que ça implique, en bien comme en mal

Les ADR sont **datés et immuables**. On ne réécrit pas un ADR : on en crée
un nouveau qui le supersede si nécessaire. Cela préserve l'historique des
choix techniques et permet de comprendre, dans plusieurs années, *pourquoi*
le projet a pris telle direction.
