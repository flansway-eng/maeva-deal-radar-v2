# Architecture

Ce dossier rassemble les schémas et explications globales de l'architecture
du projet : vue d'ensemble, diagrammes de flux entre les domaines (signals,
qualification, memory, outreach, pilotage), et décisions structurantes au
niveau système.

Pour les choix d'architecture documentés au format ADR (Context / Decision /
Consequences), voir le dossier `docs/decisions/`.

Pour la pédagogie pas-à-pas du projet, voir `docs/masterclass/`.
